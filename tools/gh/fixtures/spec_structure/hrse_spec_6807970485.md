### TC1 — Cluster of 10 or more auto-promotes (AC1)
A new cluster of 10 mentions yields a `canonical` Topic and a promotion row that is `system_committed`, `disposition = 'auto_commit'`, `decided_by = 'system:auto-commit'`, with one `auto_committed` event, and NO `open` row. Class: ac.

### TC2 — Cluster under 10 asks nothing (AC2)
A new cluster of 9 yields an `emerging` Topic and NO `topic_promotion` row. Class: ac.

### TC3 — Growth by attachment (AC3)
An `emerging` Topic with 8 members and no row, attached 2 more: `canonical` with a `system_committed` row. Guard: the same Topic with an `open` row whose `disposition` is null stays `emerging` and the row stays `open`. Class: ac.

### TC4 — Rejected promotion never auto-promotes (AC4)
Reject a Topic's promotion, then grow it past 10: it stays `emerging`. Class: ac.

### TC5 — Threshold override (AC5)
`topic_auto_promote.AUTO_PROMOTE_MIN_MEMBERS` patched to 3: a new cluster of 3 is promoted. Default is 10 when `TOPIC_CLUSTERING_AUTO_PROMOTE_MIN` is unset. Class: ac.

### TC6 — LinkedIn import (AC6, AC7)
A suggest-band match whose Person already has a different `linkedin_url` creates a Connection Person and NO `linkedin_connection` row; when the name is already taken it is counted `name_conflict` and nothing is written. The same match where the Person has no address creates a row with `disposition = 'profile_prompt'` and no Person. Re-importing the same file adds no row and no Person. Class: ac.

### TC7 — Email commitment (AC8, AC9)
A Send to Gmail commitment (`gmail_draft_id` present), `speaker_is_actor` true, no ambiguity: one Task for the operator (`owed_by = 'self'`) and a `system_committed` row whose record carries `created: true`. With ambiguity, with `speaker_is_actor` false, and a nudge-scheduler draft with no `gmail_draft_id` ("I'll send the deck Friday"): each leaves an `open` row, `disposition = 'ask'`, and NO Task. Class: ac.

### TC8 — Failures never break the caller (AC10)

### TC9 — Job change off the stream (AC11)

### TC10 — Types that keep asking (AC12)
